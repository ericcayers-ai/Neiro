Real-time player DSP (frontend/src/player/worklet/player-worklet.js)
------------------------------------------------------------------
Original clean-room implementation written for Neiro (MIT). It is a phase-vocoder
time-stretcher + linear resampler + cepstral formant warp + biquad EQ + centre
reducer. No third-party DSP library is bundled, linked, or translated.

Neiro does **not** include or use Rubber Band, `rb.wasm`, or any Tune73 commercial
build. It also does not include code, UI, images, locale strings, model CDN
artefacts, or other assets from the Transpose browser extension
(ioimlbgefgadofblnajllknopjboejda). Behaviour was reimplemented from public
capability descriptions; expression was not copied.

Browser companion (addon/)
--------------------------
Original MIT code. Uses only Chrome extension APIs (MV3) and the Web Audio API. Its
granular shifter is original and local; no remote code, no analytics, no bundled
third-party script. Optional pairing talks only to the local Neiro process at
127.0.0.1.
