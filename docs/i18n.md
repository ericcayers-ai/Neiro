# Internationalisation

English is the only shipped locale. The scaffold exists so strings are not
scattered through JSX and so a community locale can be added without touching
component code.

## Surfaces

| Surface | Catalogue | Notes |
|---|---|---|
| Shell/navigation | `frontend/src/i18n/translate.ts` (`EN`) | rail labels, hints, session menu, common actions |
| Player | `frontend/src/player/i18n.ts` | transport, scenes, MIDI, shortcuts, method labels |
| Import module | `frontend/src/i18n/translate.ts` (`EN`, `import.*`) | browse/dropzone, queue, URL fetch messages |
| Restore module | `frontend/src/i18n/translate.ts` (`EN`, `restore.*`) | gate, header, recommendation, results |
| Separate module | `frontend/src/i18n/translate.ts` (`EN`, `separate.*`) | gate, header, presets/tier labels, queue, results |
| Preferences module | `frontend/src/i18n/translate.ts` (`EN`, `prefs.*`) | sections, controls, tables, privacy; status messages remain English |
| MIDI Studio | `frontend/src/i18n/translate.ts` (`EN`, `midi.*`, `practice.*`) | shell, score/roll options, transcribe labels, practice gates; option data remains English |
| Studio (chrome) | `frontend/src/i18n/translate.ts` (`EN`, `studio.*`) | headings, tool-group labels, all tooltips/aria; help sheet/messages remain English |
| Library module | `frontend/src/i18n/translate.ts` (`EN`, `library.*`) | songs, notes, markers, clips, versions, reset |
| Everything else | JSX strings | not yet extracted; this is the remaining i18n work |

`frontend/src/i18n/index.tsx` provides `I18nProvider`, `useT()` and `useI18n()`.
The provider persists the chosen locale in `localStorage` and falls back to
English for missing keys (`translate()` also falls back to `EN` for unknown keys).
`missingKeys()` is available for a future completeness check.

## Adding a locale

1. Add a catalogue object with the same keys (do not copy another product's
   translations; write or commission them).
2. Register it in `CATALOGUES` in `frontend/src/i18n/index.tsx`.
3. Add plural/RTL handling before shipping a locale that needs it — the current
   scaffold does not implement ICU plurals or RTL mirroring.
4. Run `python scripts/a11y_static.py` and the vitest suite; both are cheap.
   `modules.ssr.test.tsx` asserts that Import/Library header strings come from the
   catalogue, so a locale regression shows up without a browser.

## Explicit non-claims

- 55 locales are **not** shipped; there are no copied Transpose locale strings or
  assets.
- The UI is not RTL-tested and has no pluralisation layer yet.
- The shell, player, Import, Library, Restore, Separate, Preferences and MIDI Studio
  surfaces are catalogued, plus Studio chrome and tooltips. The Studio help sheet,
  dynamic messages, help text and preset/option data remain English.
