Notes and limits:

- The token is per process (or `NEIRO_API_TOKEN`); the UI fetches it from
  `GET /api/auth/token`, which refuses `Sec-Fetch-Site: cross-site/same-site`.
- Tokens are compared with `hmac.compare_digest`.
- The native DAW bridge (`/api/daw/*`) is exempt from the token because it is a
  local native client and its content types are not CORS-safelisted; it still
  requires a loopback Host and an allowlisted origin.
- URL ingest checks scheme, credentials and literal private/loopback hosts. It is a
  policy guard, **not** a complete SSRF defence (redirects/DNS rebinding); yt-dlp is
  absent here, so no live fetch was exercised.
