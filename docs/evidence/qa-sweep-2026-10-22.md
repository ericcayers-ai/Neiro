## Defects found and fixed

1. **Theme not applied at startup.** Theme/density/scale were applied only while
   Preferences was mounted, so the app opened light and switched to dark on visiting
   Prefs. Added `useAppearance()` in the shell (startup) while Prefs still applies
   changes.
2. **Rail accessible names mismatched visible text** (axe serious, 9 nodes) and the
   search button aria-label omitted "Jump…/Ctrl+K". Removed the redundant aria-label
   so the content names the control.
3. **Rail hint contrast** 2.84:1 on dark active rows → `--muted` (passes 4.5:1).
4. **Import dropzone nested a focusable file input** (axe critical + nested-interactive).
   Moved the input outside the `role=button`, labelled it.
5. **Studio real-time modal ignored Escape** and leaked shortcuts to the timeline.
   The modal now owns the keyboard: Escape closes it, nothing else passes through.
6. **Job tray swallowed clicks** through its empty area (it covered Library marker
   controls). Tray/empty list is pointer-transparent; head and rows stay interactive.
7. Module sweep: 0 horizontal overflow, axe serious/critical violations 0 on all
   nine modules, 0 console/page errors.
7b. **Keyboard focus could leave the real-time modal**, and Escape was ignored while a
   control had focus (the input guard ran before the modal check). Added a focus
   trap (Tab/Shift+Tab cycle, focus first control, restore the trigger on close) and
   moved the modal check ahead of the input guard. The same trap now covers the
   command palette and the session dialog; the listener runs at document level and
   pulls focus back if it escapes. The Studio help sheet uses it too. Verified with
   10–25 Tab presses each. Focus restoration belongs to the opening control (the
   hook restoring it raced the owner and dropped focus to <body>). The shell now
   restores focus to the rail search button after the palette closes and to the
   Session button after a dialog closes.
- “Create clip from A–B” is disabled until B > A (it previously looked available
  while doing nothing on an inverted range).
8. **Cancel returned 401.** `cancelJob()` sent no auth header, so header/tray Cancel
   silently failed and the job completed. Now sends `apiHeaders(false)`; verified
   "cancelled by user" with no new artifact.
9. **Playlist count stayed stale** after "Add to Favorites" (API succeeded, UI never
   refreshed). The handler now awaits the call, refreshes and confirms.
10. **Region select was impossible on a normal track.** The clip fills the lane and
    its pointer handler moved the clip in every mode, contradicting “drag on a lane
    to select”. Select mode now starts a region selection on the clip body; clip
    moves happen only with the Move tool. Verified fades/gain/normalize/reverse and
    trim (duration 8.0 s → 3.2 s).
11. **About update check hit GitHub from the engine UI**, which CSP blocks and logs
    console errors. Non-desktop windows now say update checks run in the desktop app.
12. **Cache budget was misleading.** A request above 90% of free disk is rejected
    (400) and the effective budget is clamped, but the UI showed only the requested
    number. Prefs now shows “Effective budget … (disk free …)” and the rejection
    message; verified 1 GB applies and 999 GB warns.
13. **“Open the player after import” did nothing.** The preference set a MIDI focus
    flag while the import still navigated to Analysis. Import now routes to MIDI
    practice (and requests focus) when the preference is on; verified the practice
    panel renders and plays. Library “Resume: <song>” also verified after reload.
14. **Track headers clipped stem names** (“Res”, “Voc”, “Inst”) and the expanded job
    tray sat on top of the Mix drawer/export controls. Track head widened to 11rem;
    the tray now auto-expands only while jobs run and collapses back to the edge.
15. **Queue message undercounted** ("2 files in queue" while three were listed) and
    the collapsed tray's reopen button was unclickable after the click-through fix.
    Message no longer claims a total; the edge button is pointer-interactive again.
