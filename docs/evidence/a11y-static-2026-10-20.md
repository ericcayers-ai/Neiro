# Static accessibility audit — 2026-10-20

Command:

```powershell
.\.venv\Scripts\python.exe scripts/a11y_static.py --strict
```

Result:

```
Scanned 34 UI files

Static a11y: 0 finding(s), 0 warning(s)
```

What the check covers: images without `alt`, empty `<button>` without an
accessible name, empty `aria-label`, `<html>` without `lang`, and `onClick` on a
`div`/`span`/`li` without `role`/`tabIndex`. One finding was fixed during the pass
(the restored-audio `<audio>` element now has an `aria-label`); the drag-drop
import zone was already a proper `role="button"` with keyboard handling.

What this does **not** prove: WCAG conformance, label association, focus order,
contrast, live-region usefulness, or screen-reader announcements. Those remain the
owner-run checks in `docs/accessibility.md`.
