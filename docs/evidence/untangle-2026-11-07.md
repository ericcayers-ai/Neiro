## Phase 4 — the incredulous question

Largest first-party module is `src/neiro/ui/server.py` (108.6 KB). What it does: the HTTP surface of
the engine. Why it is this big: one route handler per endpoint, no router split. What would break if
half were deleted: the served UI and every client call — so it is a **next-pass** finding, and a
router split is a structural change, out of scope for a zero-risk pass.

Left for the next pass (all require a behaviour-aware change, so none was taken here):

- `src/neiro/ui/server.py` 108.6 KB — split along the route-table seam (the one named seam).
- `frontend/src/modules/StudioModule.tsx` 105.4 KB — split along module seams, not before the
  117-test practice gate covers it (it does not: it is not a practice module).

  coverage that is owner-run, so it is excluded.
